**Course:** CIP-B101
**Lab:** Lab 1C – Windows Command Line Forensic Basics

## Overview

This lab demonstrates core Windows Command Line (CMD) and PowerShell skills
used in digital forensic investigations — creating a structured case
workspace, collecting system/network evidence, and documenting findings
using built-in Windows utilities.

## Environment

- OS: Microsoft Windows 11 Pro (Build 26200)
- CPU: Intel(R) Core(TM) i5-7300HQ @ 2.50GHz
- Memory: 16,304 MB
- Shell: CMD and PowerShell

## Tasks Performed

### 1. Directory & File Operations
- Created the case folder and subfolders (`mkdir`)
- Navigated the file tree (`cd`, `tree`, `dir`)
- Created and read text files (`echo`, `type`)
- Copied, moved, renamed, and deleted files (`copy`, `move`, `ren`, `del`)
- Created and removed a test folder (`mkdir` / `rmdir`)
- Backed up a workspace folder recursively (`xcopy /E /I /H /Y`)

### 2. Evidence Documentation
- Logged student/course metadata to `evidence_note.txt`
- Created `mini_case_log.txt` with mock case details (user, email, IP, keyword)
- Searched the log for specific terms using `findstr` (with `/i` case-insensitive
  and `/n` line-number flags)
- Checked file permissions on evidence with `icacls`

### 3. System Information Collection
Collected into `outputs\`:
- Full system info (`systeminfo > systeminfo_full.txt`)
- Filtered OS/BIOS/system type/memory details (`systeminfo | find`)
- CPU info via PowerShell (`Get-CimInstance Win32_Processor`)
- Disk info via PowerShell (`Get-CimInstance Win32_DiskDrive`)

### 4. Network Information Collection
- Full IP configuration (`ipconfig /all`)
- Filtered IPv4 addresses and gateways (`ipconfig | findstr`)
- MAC/adapter details (`getmac /v`)
- Connectivity tests to loopback, a public DNS (8.8.8.8), and a domain
  (`google.com`) using `ping`

### 5. Process Enumeration
- Captured running processes (`Get-Process > process_list.txt`)
- Filtered specific processes by name (chrome.exe, msedgewebview2.exe) with
  `Get-CimInstance Win32_Process` and command-line details

### 6. Scripting
- Wrote and ran a simple `hello_world.bat` script
- Wrote and ran `sys_info.bat`, a batch script that automatically collects
  Windows, hardware, and network info into `outputs\sys_info_report.txt`
- Re-ran the script from a different working directory to confirm it works
  regardless of caller location

## Key Commands Used

| Command | Purpose |
|---|---|
| `mkdir` / `rmdir` | Create/remove directories |
| `dir` / `tree` | List directory contents/structure |
| `cd` | Change directory |
| `echo` / `type` | Write to and read text files |
| `copy` / `move` / `ren` / `del` | File management |
| `xcopy /E /I /H /Y` | Recursive folder backup |
| `findstr` | Search text within files |
| `icacls` | View/manage file permissions |
| `systeminfo` | System information |
| `ipconfig` / `getmac` | Network configuration |
| `ping` | Connectivity testing |
| `Get-Process`, `Get-CimInstance` | PowerShell system/process queries |
